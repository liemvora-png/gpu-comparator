# GPU Comparator - Liquid Glass Style

A modern, responsive web application to compare GPU products from NVIDIA, AMD, and Intel using a "liquid glass" design language.

## Features

- **Liquid Glass UI**: High-end glassmorphism effects using `backdrop-filter` and complex `box-shadow`.
- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop.
- **Dynamic Rendering**: GPU data is rendered via JavaScript.
- **Smooth UX**: Interactive buttons and smooth scrolling.

## Tech Stack

- HTML5
- CSS3 (Glassmorphism, Flexbox, Grid)
- Vanilla JavaScript

## Getting Started

Simply open `index.html` in any modern web browser to view the application.
