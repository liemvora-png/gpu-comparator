# GPU Liquid Glass Comparator

A modern, fully responsive web application for comparing GPU products from NVIDIA, AMD, and Intel. Featuring a stunning "Liquid Glass" (Glassmorphism) design.

## Features
*   **Liquid Glass UI**: Beautiful, translucent interface with high-quality blur effects.
*   **Interactive Comparison**: Browse and compare a vast selection of GPUs.
*   **Real-time Search & Filter**: Quickly find specific GPUs or filter by manufacturer.
*   **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
*   **Modern Aesthetics**: Smooth animated mesh gradient background.

## Tech Stack
*   HTML5
*   CSS3 (Glassmorphism & Animations)
*   Vanilla JavaScript

## Getting Started
Simply open `index.html` in your favorite web browser to start comparing!
